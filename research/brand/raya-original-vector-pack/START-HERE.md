# Raya London original design in vector form

Use SVG/raya-original-vector-black.svg for the original colour arrangement and black lettering. White- and navy-lettering alternatives are included; the four badge colours remain the same in each.

These are genuine vector files. The symbols and original lettering are shapes, and the silver rims use gradients. There are no embedded pixel images, font dependencies or bitmap effects. The artwork can be enlarged without pixelation. PNG copies exported from these vectors are included at 1,259 and 5,036 pixels wide.

The wording, quotation marks, four symbols, their order and the original layout have been retained. No replacement typeface or new design has been introduced. The source image is preserved in Reference/raya-original.png.

## Fidelity

A pixel image cannot be converted into smooth vector curves with a guaranteed 100% pixel-for-pixel match. This is a close trace of the original design. The symbols and lettering follow the source outlines; small edge irregularities have been smoothed, the badge circles have been fitted to the source, and silver shading has been reconstructed as gradients sampled from it. These operations create small differences, particularly around the rims and softened original edges.

Open preview.html to compare the original and vector at the same scale. Use its slider or buttons to switch between them. If absolute visual identity to every source pixel is required, use the untouched original; this vector version should not be described as pixel-identical.
